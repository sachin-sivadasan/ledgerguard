# 25. Flutter Risk Analysis

## What It Does
Visualizes subscription risk distribution through a funnel chart (SAFE → ONE_CYCLE → TWO_CYCLES → CHURNED) with counts and revenue impact. Displays risk mitigation playbooks — actionable guides for each risk state. Provides drill-down to at-risk subscription lists.

## Architecture
Presentation layer. `RiskProvider` computes risk distribution from mock subscriptions and provides playbook data. `RiskScreen` renders the risk funnel visualization, at-risk subscription list, and playbook cards.

## Key Files
| File | Lines | Purpose |
|------|-------|---------|
| `ledgerguard-flutter/lib/providers/risk_provider.dart` | ~80 | Risk distribution computation, playbook data |

## Data Flow
```
MockSubscriptions → RiskProvider
    ├��─ riskDistribution (count per state)
    ├── revenueByRisk (MRR per state)
    ├── atRiskSubscriptions (ONE_CYCLE + TWO_CYCLES)
    └── playbooks (per risk state)
         │
         ▼
    RiskScreen
    ├── Risk Funnel (bar chart with colors)
    ├── At-Risk Subscriptions list
    └── Playbook cards (mitigation steps)
```

None — mock data.

## State Machine
```
RiskProvider (ChangeNotifier)
  State:
    _selectedAppId: String?   → null (all apps)

  Events:
    setSelectedApp(appId) → filter by app

  Computed:
    riskDistribution → {safe: N, oneCycle: N, twoCycles: N, churned: N}
    revenueByRisk    → {safe: $X, oneCycle: $Y, ...}
    atRiskSubscriptions → subs in ONE_CYCLE or TWO_CYCLES
    playbooks        → action items per risk state
```

## Gotchas
- Risk funnel colors: green (safe), orange (one cycle), red-orange (two cycles), red (churned)
- Playbooks are static content — not generated by AI
- "At-risk" includes ONE_CYCLE_MISSED and TWO_CYCLES_MISSED only (not churned)
- Revenue shown per risk state helps prioritize which subscriptions to save
